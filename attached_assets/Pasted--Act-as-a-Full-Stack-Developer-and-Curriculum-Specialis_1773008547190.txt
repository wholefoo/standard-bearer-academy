Recommended Tech Stack for Replit
To make this platform "extensive," I suggest using the following tools within Replit:

Database: Use PostgreSQL (available via Replit's managed database) to store student progress, quiz scores, and the massive amount of curriculum text.

Frontend: Streamlit (Python-based) is the fastest way to build a clean, functional dashboard without deep CSS knowledge. If you want a more "app-like" feel, use Next.js.

AI Integration: You will likely want to use the OpenAI or Anthropic API to help generate the sheer volume of "courseware" text based on your specific worldview prompts.
